# 💖 S.O.AI.Deal Mind

Voice-first AI copilot for authentic shopping + lifestyle rescue.

### What it does
- Finds authentic outfit (Dress + Shoes + Bag) at lowest price
- Books top-rated open salon near you - Sunday Rescue
- Unlocks 40% cross-merchant reward
- One prompt = full plan ready for approval

### Tech Stack
- FastAPI (Python)
- HTML / CSS / JS Frontend
- PayPal Sandbox Ready

### How to Run

uvicorn main:app --reload
